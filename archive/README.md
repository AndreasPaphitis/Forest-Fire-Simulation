# Archive Directory

This directory contains archived code, documentation, and old project structures that are no longer actively used but preserved for reference.

## Structure

### old_numbered_structure/
Original numbered folder structure (01-06) from early project organization:
- `03_analysis_code/` - Original analysis code structure
- `05_documentation/` - Original documentation folder
- `06_supplementary/` - Original supplementary materials

### backup_files/
Backup copies of files that were replaced or updated:
- `forest_model_backup.py` - Backup of forest model
- `forest_model_original.py` - Original forest model implementation
- `sensitivity_objective_backup.py` - Backup of sensitivity objective
- `sensitivity_objective_fixed.py` - Fixed version (superseded)
- `objective_functions_corrected.py` - Corrected objective functions (superseded)
- `config_tools.py.backup` - Config tools backup
- Terrain preprocessor backups

### historical_docs/
Historical documentation and planning files:
- `IMMEDIATE_ACTION_PLAN.md` - Early action plans
- `QUICK_REPORT_TEMPLATE.md` - Report templates
- `HISTORICAL_DOCUMENTATION.md` - Historical documentation
- `DEADLOCK_DIAGNOSTIC_RESULTS.md` - Deadlock diagnostics
- `EMBER_TRACKING_IMPLEMENTATION.md` - Ember tracking notes
- `CLEAN_WORKSPACE_SUMMARY.md` - Workspace cleanup notes
- `FIXED_OUTPUTS_SUMMARY.md` - Output fixes summary
- Configuration and error fix notes

## Purpose

This archive preserves:
1. **Historical Context**: Original project structure and organization
2. **Development History**: Backup files showing evolution of the codebase
3. **Documentation**: Historical plans, fixes, and decisions
4. **Reference**: Old implementations that may be useful for understanding design decisions

## Usage

These files are for reference only and should not be used in active development. The current codebase in `src/`, `scripts/`, and other directories represents the production-ready code.

## Cleanup

Files are archived here during major reorganizations. They can be safely deleted if storage space is needed, but keeping them provides valuable project history.
